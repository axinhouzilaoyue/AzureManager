Azure 控制台字段对照

添加账户时，请按下方对照从 Azure 门户复制值。左侧是门户里常见名称，右侧是本面板字段。

Azure 门户名称 本面板字段 常见位置
Application (client) ID 应用 (客户端) ID Microsoft Entra ID → 应用注册 → 概述
Directory (tenant) ID 目录 (租户) ID 同上，概述页
Client secret Value 客户端密钥 Value 应用注册 → 证书和密码 → 新建客户端密码
注意复制 Value，不是 Secret ID
Subscription ID 订阅 ID 订阅 → 概述

快速开始

  • 在 Entra ID 创建应用注册，并生成客户端密码
  • 在目标订阅 IAM 中给该应用分配 Contributor
  • 回到面板「添加账户」，粘贴四个 ID/密钥后先「验证凭据」
  • 验证通过后保存，进入账户即可管理虚拟机

虚拟机操作

  • 启动 / 停止 / 重启：控制电源状态
  • 换 IP：释放旧公网 IP，绑定新静态 IP
  • 删除：删除整资源组（VM 及关联网络资源）
  • 创建与运维任务都是异步的，可在「任务」页查看进度与 SSH 信息

数据与迁移

账户凭据（加密）与任务记录保存在挂载目录的 data/ 中。迁移时复制整个 data/ 目录即可。

添加 Azure 账户
字段已按 Azure 门户命名。 应用/租户 ID 来自「应用注册 → 概述」；密钥请复制新建客户端密码时的 Value（不是 Secret ID）；订阅 ID 来自「订阅 → 概述」。
路径：Entra ID → 应用注册 → 证书和密码 → 新建客户端密码。只在创建时显示一次。
