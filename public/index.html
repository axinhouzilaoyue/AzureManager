如何获取凭据
也兼容 clientId / clientSecret / tenantId / subscriptionId 等常见键名。
请先验证凭据，通过后才能保存。下一步将填写邮箱与订阅到期日。
推荐用 Azure Cloud Shell 一条命令创建服务主体（Service Principal）。 成功后会输出 JSON，可直接粘贴到「添加账户」里自动填充。 说明参考自开源项目的常见做法。

1打开 Azure Cloud Shell

  • 访问 https://portal.azure.com 并登录
  • 点击顶部工具栏的 Cloud Shell（>_ 图标）
  • 环境选择 Bash

2一键创建 Contributor 服务主体

把下面整段命令粘贴到 Cloud Shell 执行：

sub_id=$(az account list --query '[0].id' -o tsv) && az ad sp create-for-rbac --role contributor --scopes /subscriptions/$sub_id && echo "subscriptionId=$sub_id"
  • 命令会：读取当前默认订阅 ID → 创建 SP → 赋予该订阅 Contributor 角色
  • 最后额外打印一行 subscriptionId=...，方便你复制订阅 ID
  • 若你有多个订阅，可先执行 az account list -o table，再用 az account set --subscription <订阅ID或名称> 切到目标订阅后再跑上面命令

3保存命令输出的 JSON

成功后会得到类似：

{{
  "appId": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "displayName": "azure-cli-2025-....",
  "password": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "tenant": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
}
subscriptionId=yyyyyyyy-yyyy-yyyy-yyyy-yyyyyyyyyyyy
  • 请完整复制保存，尤其是 password，之后无法再查看
  • 回到本面板「添加账户」，可用 粘贴 JSON 一键填充

4JSON / 字段对照

Cloud Shell JSON / 输出 本面板字段 说明
appId 应用 (客户端) ID 也叫 Application (client) ID
password 客户端密钥 Value 服务主体密钥，只显示一次
tenant 目录 (租户) ID 也叫 Directory (tenant) ID
subscriptionId=... 或订阅概述页 订阅 ID 上面命令末尾会打印；也可在门户「订阅 → 概述」复制
displayName（可选） 显示名称 可改成你自己好记的名字

5回到本面板添加

  • 打开「添加账户」
  • 方式 A：切换到 粘贴 JSON，把整段输出贴进去点「解析并填充」
  • 方式 B：切换到 手动填写，按对照表逐项输入
  • 先点「验证凭据」，通过后再「保存账户」

6（可选）查询可用区域

若订阅有区域策略限制，可在 Cloud Shell 执行：

az policy assignment list --disable-scope-strict-match --query "[?parameters.listOfAllowedLocations].parameters.listOfAllowedLocations.value[]" -o tsv | sort -u
